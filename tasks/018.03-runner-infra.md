## Infra: Bucket, Runner Task Definition, Roles

Part of epic 018. The OpenTofu stack deploys underling in ECS mode: a bucket for the run files, a runner task definition, and roles split between underling and the runner.

### Acceptance Criteria

- **Bucket.** Private, encrypted, no public access. Objects under `runs/` expire after one day.
- **Runner task definition.** The runner command, its own log stream prefix, no secrets, and CPU, memory and ephemeral storage as variables. Its task role is today's Bedrock policy and nothing else.
- **underling's task role.** Start the runner task definition only, describe and stop tasks in the cluster, pass only the runner's two roles, and read, write and delete objects under `runs/`. It loses Bedrock.
- **Service.** Runs in ECS mode with 018.02's configuration wired from the stack.
- **Network.** The runner gets its own security group: no inbound, outbound 443 only. It runs in today's public subnets with a public IP.
- **Probe.** The sandbox probe's task definition, outputs and runbook step go from `infra/`. The image keeps its probe script and bubblewrap.
- **Checks.** `make infra-check` passes, and the mocked-provider tests cover both roles.
- **Docs.** infra/README.md's runbook and troubleshooting match the new stack, including where the runner's logs are.
