## ECS Driver

Part of epic 018. underling's ECS mode, on 018.01's contract.

### Acceptance Criteria

- **Config.** `INVESTIGATION_RUNNER=ecs` turns the mode on; unset means in-process, as today. ECS mode needs Bedrock mode, plus the cluster, the runner task definition and its container name, subnets, security groups, whether to assign a public IP (default off) and the bucket. Anything missing or invalid fails startup. The other settings parse as today, but in ECS mode no startup or per-run check touches `claude`, the plugin dirs or the sandbox's paths.
- **Run.** For each investigation underling uploads the input under `runs/<runId>/input/`, presigns the four URLs so they stay valid for the whole run (the epic's 10 minutes to start, the timeout and the 2-minute backstop), starts the task with the contract's environment as overrides, polls until it has stopped, then takes the output and carries on as today.
- **Outcomes.**
  - Upload, presigning or starting the task fails, the task stops before its container ran, or it isn't running after 10 minutes (then it is stopped): Failed, new stage `runner`, with the reason.
  - The task stopped and left no result: Failed `claude`, naming the stop reason and exit code. A result that is there counts, whatever the exit code.
  - A failed poll is retried until the backstop; it doesn't fail the run by itself.
  - Result `failed`: Failed `claude` with the result's reason. Result `timeout`: Failed `timeout`.
  - Result `ok`: today's checks, push and PR.
- **Backstop.** A task still running 2 minutes after `INVESTIGATION_TIMEOUT`, counted from when it started running, is stopped; the outcome is Failed `timeout`.
- **Shutdown.** When underling shuts down mid-run it stops the task and records Failed `shutdown`.
- **Cleanup.** The run's objects are deleted when the run ends, whatever the outcome.
- **Tests without AWS.** Each outcome above is specified against fakes of ECS and S3.
- **Docs.** docs/event-model.md covers the mode, its configuration, the new stage and the AWS permissions underling needs for it.

### Notes

- Presigned URLs die with the credentials that signed them. The existing rule for Bedrock credentials (refetch any that would expire within the timeout) applies to the signing credentials too.
